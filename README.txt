MEAL PLANNER - how to put it online (GitHub Pages)

1. On github.com click + > New repository. Name: meal-planner. Set it to Public. Create.
2. Click "uploading an existing file". Unzip this folder first, then drag in ALL files
   (index.html, manifest.json, sw.js and the 4 png icons). Click Commit changes.
3. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
4. Wait 1-2 minutes. Your link: https://YOUR-USERNAME.github.io/meal-planner/

Install on Android: open the link in Chrome > three dots > Install app (or Add to Home screen).
Before that, uninstall any older "Plate Planner" app from the phone.
